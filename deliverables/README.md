# Deliverables

Three deployable static archives, kept together for handover.

- `consolidated-engineers.zip` - this repository, the Consolidated Engineers rebuild.
- `relco-handicrafts.zip` - the separate RELCO Handicrafts store.
- `relco-leather-goods.zip` - the separate RELCO Leather store.

Each archive extracts to a site root with `index.html` at the top level. None of them needs a build step.
